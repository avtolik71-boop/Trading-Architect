# Скиллы проекта Trading Architect

Эта папка содержит **скиллы в формате DeepSeek Harness (DSH)** — переиспользуемые наборы инструкций. Каждый скилл — каталог с файлом `SKILL.md`, где в YAML-frontmatter заданы `name` и `description`, а тело — инструкции.

## Состав

| Скилл | Файл | Когда использовать |
|---|---|---|
| `hurst-methodology` | `hurst-methodology/SKILL.md` | Показатель Херста: структура рынка, точки входа, фильтрация стратегий, риск T^H |
| `hurst-indicators` | `hurst-indicators/SKILL.md` | Индикаторы Херста для cTrader (C#) и MT5 (MQL5): сборка, установка, чтение графики |
| `trading-architect` | `trading-architect/SKILL.md` | Проект Trading Architect: структура, реестры, точки расширения, промпты |

## Формат скилла

```markdown
---
name: my-skill
description: Use when ... (условие активации скилла)
---

# Заголовок
... инструкции ...
```

- `name` — уникальный id (совпадает с именем каталога).
- `description` — условие, по которому агент решает, когда загружать скилл. Пишется на английском, кратко и конкретно.

## Установка в DeepSeek Harness

Скиллы в этой папке — «исходники». Чтобы они стали активными скиллами DSH (появлялись в каталоге доступных скиллов сессии), их нужно установить в профиль DSH. Способы:

1. **Вручную** — скопировать каталог скилла в каталог скиллов профиля (`%USERPROFILE%\.dsh\profiles\<profile>\...`) согласно структуре, принятой в вашей версии DSH.
2. **Через bundle/плагин** — оформить скиллы как пакет-расширение DSH (рекомендуется для переносимости). Для этого используется `dsh-doc` → `references/tool-design.md` и шаблоны bundle.

> Точное место установки зависит от версии DSH. Перед установкой сверьтесь со skill `dsh-doc` в вашем окружении.

## Как скиллы связаны с проектом

- `hurst-methodology` и `hurst-indicators` кодируют методику, по которой написаны индикаторы в соседней папке `Desktop\DeepSeek PROJECT\ИНДИКАТОР ХЕРСТА`.
- `trading-architect` описывает, куда методика встроена в коде проекта: `research/indicators/indicator_registry.py` (индикатор + фильтр `hurst_regime`) и `research/catalogs/idea_strategy_registry.py` (идея I-016).
