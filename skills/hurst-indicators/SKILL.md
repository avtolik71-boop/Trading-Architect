# Индикаторы Херста (cTrader + MT5)

Два индикатора, реализующие методику `hurst-methodology` как графический индикатор: скользящий показатель Херста + классификация режима с гистерезисом.

Файлы (проект «ИНДИКАТОР ХЕРСТА», соседняя папка):
- cTrader: `cTrader\HurstRegimeIndicator.cs`
- MT5: `MT5\HurstRegimeIndicator.mq5`

## Логика (одинакова в обеих платформах)

1. Лог-доходности `x(t) = ln(P_t/P_{t−1})` в скользящем окне (по умолч. 250 баров).
2. Оценка H методом **DFA** (осн.), **R/S** или средним; полиномиальный детрендинг 1–3.
3. Пересчёт H каждые `Step` баров (по умолч. 5), между ними — удержание значения.
4. Классификация режима с гистерезисом: ТРЕНД (H>0,58 вход / <0,52 выход), ШУМ (≈0,5), ВОЗВРАТ (H<0,42 вход / >0,48 выход).
5. Графика: трёхцветная линия H(t), пунктирные уровни порогов, статус режима.

## Графика и чтение

| Цвет | Режим | Торговый смысл |
|---|---|---|
| 🟢 зелёный | ТРЕНД | тренд-следования (пробой каналов, MA, моментум) |
| ⚪ серый | ШУМ | не торговать / снизить риск до 0–50% |
| 🔴 красный | ВОЗВРАТ | контртренд (Боллинджер, RSI, парный трейдинг) |

- Верхний зелёный пунктир = порог тренда (0,58), серый = 0,5, нижний красный = порог возврата (0,42).
- Смена цвета = смена режима → переключение пула стратегий (не мгновенный вход).
- MT5: крупный цветной бейдж `РЕЖИМ / H / окно` в углу подокна (текст цвета режима на чёрном фоне). cTrader: цветная метка `РЕЖИМ: … H = …` на последнем баре + вертикальная линия цвета режима.

## Параметры

| Параметр | По умолч. | Назначение |
|---|---|---|
| Длина окна | 500 | размер окна оценки H (250 статистически недоопределено) |
| Шаг пересчёта | 5 | через сколько баров пересчитывать H |
| Метод | DFA | DFA / R/S (Анис–Ллойд) / DFA+R/S |
| Порядок детрендирования | 1 | 1–3 (линейный — стандарт) |
| Мин. масштаб n | 8 | минимальный блок DFA/R/S |
| Тренд вход/выход | 0,58 / 0,52 | пороги гистерезиса |
| Возврат вход/выход | 0,42 / 0,48 | пороги гистерезиса |

## Установка

- **cTrader:** Automate → Indicators → New → вставить `.cs` → Build. Или скопировать в папку Sources индикаторов.
- **MT5:** MetaEditor (F4) → New → Custom Indicator → вставить `.mq5` → Compile (F7). Или скопировать в `MQL5\Indicators\`.

Индикатор открывается в **отдельном подокне** (`IsOverlay=false` / `indicator_separate_window`).

## Ключевые детали реализации

- DFA: профиль → лог-сетка масштабов (8 точек от MinScale до N/2) → полиномиальный МНК-тренд (порядок 1–3) → `F(n)` → наклон регрессии = H, клип [0,1].
- R/S: блоки длины n → `R=max Y−min Y`, `S` → **поправка Аниса–Ллойда** (деление на E[R/S(n)]) → наклон `ln((R/S)/E[R/S])` = H−0.5 → `H = 0.5 + slope`. Без поправки белый шум даёт H≈0.57 (ложный тренд).
- Нет перерисовки: H считается по закрытым барам (окно сдвинуто на 1). MT5: начальный буфер EMPTY_VALUE + `OnDeinit` чистит Comment. Average показывает Δ = |DFA−R/S| и флаг «расхождение» при Δ>0.15.
- Гистерезис — конечный автомат: `ТРЕНД →(H<TrendExit)→ ШУМ`, `ШУМ →(H>TrendEntry)→ ТРЕНД / →(H<MrEntry)→ ВОЗВРАТ`, `ВОЗВРАТ →(H>MrExit)→ ШУМ`.
- cTrader: три выхода `IndicatorDataSeries` (тренд/шум/возврат) с `double.NaN` для пустых сегментов + три константных пунктирных уровня; `Chart.DrawText` для статуса и меток.
- MT5: `DRAW_COLOR_LINE` (буфер значений + буфер цветового индекса 0/1/2), уровни через `IndicatorSetInteger(INDICATOR_LEVELS/LEVELVALUE/LEVELCOLOR)`.

## Ограничения

- Индикатор показывает **режим**, не сигнал и не направление.
- История ≥ 500–1000 баров для устойчивой оценки; окно ≥ 250.
- H доходностей ≠ H волатильности.
- Развивающиеся рынки: калибровать пороги.
