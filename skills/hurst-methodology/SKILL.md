# Методика Херста: структура рынка, точки входа, фильтрация стратегий

Показатель Херста H описывает скорость роста размаха/разброса с горизонтом:
`R/S(n) ∼ c·n^H`, для самоподобного процесса `std(x(t+τ)−x(t)) ∼ τ^H`. Фрактальная размерность `D = 2 − H`.

Главный принцип: **H отвечает не за то, КОГДА входить, а за то, КАК торговать.** Режим (по H) выбирает пул стратегий и правила входа; саму точку входа дают отдельные правила внутри режима.

## Интерпретация H

| H | Поведение | Для рынка |
|---|---|---|
| = 0,5 | случайное блуждание | нет памяти, прогноз бесполезен |
| 0,5 < H ≤ 1 | персистентность | рост → рост; тренд-следование |
| 0 ≤ H < 0,5 | антиперсистентность | рост → падение; контртренд |

Связи: для приращений fBm автокорреляция лага 1 `ρ = 2^(2H−1) − 1`; для ARFIMA(0,d,0) `H = d + 0,5`.

## Оценка H (всегда 3 метода, требовать согласование)

- **DFA** (основной, устойчив к трендам): профиль `Y(k)=Σ(x−m)` → вычесть полиномиальный тренд (порядок 1–3) в окнах длины n → среднеквадратичная флуктуация `F(n)` → наклон `ln F(n)` по `ln n` = α ≈ H (для доходностей).
- **R/S** (Херст–Мандельброт): блоки длины n, размах `R=max Y−min Y`, `S`, усреднить `R/S`, **поправка Аниса–Ллойда** (деление на E[R/S(n)]), наклон `ln((R/S)/E[R/S])` по `ln n` = H−0.5 → `H = 0.5 + slope`. Без поправки на белом шуме H≈0.57±0.06 — ложный тренд. Чувствителен к краткосрочной зависимости (модификация Ло).
- **Вейвлеты / GPH** (частотная область): оценка d, `H = d + 0,5`.
- Другие: агрегированная дисперсия, Хигучи, MF-DFA (мультифрактальность).

Если разброс оценок > 0,10–0,15 — ряд несамоподобен, H как фильтр не использовать.

**Проверка значимости (обязательна, H=0,56 сам по себе ничего не доказывает):**
- **Shuffle-тест:** 1000+ перемешиваний доходностей → распределение H; реальный H значим, если вне 95% интервала.
- **Суррогаты** (фазово-рандомизированные), **блочный бутстрэп** (доверительные интервалы).
- Устойчивость к диапазону масштабов, порядку детрендирования, длине ряда (N ≥ 500–1000).
- Согласование методов (R/S, DFA, вейвлеты сопоставимы).

## Режим рынка (скользящий H(t) + гистерезис)

Скользящее окно: 250–500 наблюдений, шаг 5–20. Две пары порогов (вход/выход), чтобы не дёргаться:

| Режим | Порог входа | Порог выхода |
|---|---|---|
| ТРЕНД | H > 0,58 | H < 0,52 |
| ШУМ | 0,48–0,52 держится | — |
| ВОЗВРАТ К СРЕДНЕМУ | H < 0,42 | H > 0,48 |

Режим валиден только если: (1) H в зоне по гистерезису; (2) shuffle-тест значим; (3) направление подтверждено (ADX/наклон/ширина канала). Пороги калибровать под инструмент (развивающиеся рынки: H выше).

**Подтверждение структуры:** CUSUM / Bai–Perron / тест Чоу (сдвиги), Markov switching / HMM (скрытые режимы), GARCH/EGARCH (волатильность), вейвлеты (циклы), EMD/Гильберт–Хуанг (нелинейные тренды), энтропия (сложность), MF-DFA (мультифрактальность), ML (GB/LSTM) на признаках с H(t).

## Точки входа по режиму

- **Тренд (H > 0,58):** пробой N-барного максимума (Дончиан/Кельтнер) с объёмом; моментум-продолжение после паузы; откат к EMA(20/50)/VWAP и отскок. Тейк — трейлинг.
- **Возврат к среднему (H < 0,42):** выход за Боллинджер 2σ + RSI 30/70; z-score цены ±2 с возвратом внутрь; парный трейдинг (коинтеграция + DCCA), спрэд ±2σ. Тейк — у средней.
- **Шум (H ≈ 0,5):** не входить (или скальп с 0–50% риска).

Универсально: вход по закрытию свечи; один сигнал = одна позиция; тайм-аут (тезис «испарился» → закрыть); отмена при пересечении порога выхода режима.

## Фильтрация и выбор стратегии

| H(t) | Включить | Выключить |
|---|---|---|
| > 0,58 | пробой каналов, MA, моментум | контртренд, Боллинджер-реверс, RSI-против |
| 0,48–0,52 | ничего (или скальп) | всё направленное |
| < 0,42 | Боллинджер-реверс, парный, RSI | тренд-следование |

Смена режима (пересечение порога с гистерезисом) = **событие переключения пула стратегий**, а не мгновенный вход. Ждать первый валидный сигнал в новом режиме.

Чек-лист сделки (все = ДА): режим H; значимость shuffle; мультитаймфрейм-согласие; ATR-диапазон; ликвидность/спред; календарь (новости); нет свежего структурного сдвига; нет стресс-сигнала MF-DFA.

## Риск и размер позиции

- H ≈ 0,5: риск `σ·√T`.
- H ≠ 0,5: **`σ(T) = σ(1)·T^H`**. Пример: H=0,6, горизонт 20 дней → риск выше √T в `20^(0,6−0,5) ≈ 1,35` раза (+35%). На практике эффект слабее — оценивать H на нужном масштабе.
- `size = risk_budget / (σ(1)·T^H · price · k)`; в шумовом режиме risk_budget × 0–0,5. VaR/ES — с поправкой T^H.

## Сигналы стресса / неэффективности

- Долговременное отклонение H от 0,5 — признак неэффективности.
- Резкое падение H + рост мультифрактальности (ширина MF-DFA) + рост волатильности — ранний сигнал кризиса (не единственный).
- H модуля доходностей и реализованной волатильности обычно ≫ 0,5 (долгая память волатильности); логарифм волатильности — rough volatility, H ≈ 0,1.

## Алгоритм исследования

① данные + очистка → ② лог-доходности + тесты (ADF/KPSS, ARCH-LM, Ljung–Box) → ③ H тремя методами → ④ значимость → ⑤ скользящий H(t) + режимы → ⑥ сверка со сдвигами → ⑦ стратегия/риск с H(t) как фильтром → ⑧ OOS (разделение, walk-forward, комиссии/проскальзывание) → ⑨ чувствительность + документация.
